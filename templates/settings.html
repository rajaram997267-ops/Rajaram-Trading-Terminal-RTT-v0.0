Auto-pick the best exit strategy for each 9:15 volume band ...
Uses the Exit Compare replays: every past trade replayed through RSI Simple, RSI Momentum, 1st 5 Min FIB and the 5-EMA trail, grouped by 9:15 volume band. A band uses the rule with the best average % - but only if it has enough replayed trades and the rule beats what actually ran there by the margin below; and it must lead the second-best rule clearly over the same trades, not just through one or two big trades (the "confidence" box: about 2 is a normal bar, higher is stricter, 0 switches this check off); otherwise that band keeps your default strategy. Recomputed once a day and when you press Rebuild now, from whatever Exit Compare has replayed so far (run "Replay new trades" there to add recent trades). Priority: a band chosen by hand above, then the rotation test below, then this. The 5-EMA trail has no live version of its own - live trades use the normal live exit rule when it is picked.
